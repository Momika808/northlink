# Northlink — лендинг

Одностраничный сайт личного VPN-контура: что это, где входные узлы и как
подключиться на iOS, Android, Windows, macOS и телевизоре.

Страница статическая и без единого внешнего запроса при загрузке — ни
шрифтов, ни аналитики, ни библиотек; в сеть она выходит только по действию
человека (код → чат с ботом). Это не аскетизм: конфиг нужен ровно тогда, когда
туннель уже не работает, и страница обязана открыться на умирающем канале.

## Раскладка

| | |
|---|---|
| `index.html` | вся страница: разметка, стили и скрипт в одном файле |
| `.nojekyll` | GitHub Pages отдаёт файлы как есть, без сборки Jekyll |

## Правки

Меняется один файл, публикуется коммитом в `main` — Pages пересобирает сам.

- **Адрес подписки** — блок «Ваша ссылка выглядит так» и `data-copy` у кнопки.
- **Бот** — секция `#access` и ссылки `t.me/...`; имя бота встречается в
  нескольких местах, менять все.
- **Города** — секция `#nodes`, по карточке на узел.
- **Приложения** — секция `#connect`, по вкладке на платформу.
- **Чат с ботом** — секция `#get`: код уходит на
  `https://cdn.adminwg.dad/api/chat/start` (бот northlink), в ответ приходят
  ссылка и сессия Matrix (`matrix.adminwg.dad`); дальше страница говорит с
  сервером сама — `/sync` длинным опросом, `PUT …/send`, картинки с жетоном.
  Библиотек нет, API клиента Matrix вызывается голым `fetch`. Кнопки под
  сообщениями бота — поле `dad.adminwg.northlink.choices` в событии,
  «скопировать» — `…copy`. Сессия и ссылка лежат в `localStorage`
  (`northlink.matrix`, `northlink.issued`) — только в этом браузере.
  Два адреса, куда страница ходит после действия человека, — единственные
  внешние запросы; при загрузке их по-прежнему ноль.
- **Индексация** — `<meta name="robots" content="noindex, nofollow">` в `<head>`.
  Строка стоит намеренно: прямая ссылка работает, поисковики и сканеры
  блок-листов страницу не находят. Убирается одной правкой.

## Чего здесь нет

Адресов узлов, домена панели, ключей и любых других данных контура.
Инфраструктура живёт в отдельном закрытом репозитории; сюда попадает только
то, что и так видит любой человек с подпиской.
