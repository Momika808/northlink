# Northlink — лендинг

Одностраничный сайт личного VPN-контура: что это, где входные узлы и как
подключиться на iOS, Android, Windows, macOS и телевизоре.

Страница статическая и без единого внешнего запроса при загрузке — ни
шрифтов, ни аналитики, ни библиотек; в сеть она выходит только по действию
человека (код → чат с ботом). Это не аскетизм: конфиг нужен ровно тогда, когда
туннель уже не работает, и страница обязана открыться на умирающем канале.

## Раскладка

| | |
|---|---|

## Правки

Меняется один файл, публикуется коммитом в `main` — Pages пересобирает сам.

С 13.09.2026 страница — один экран: название, две фразы, окно чата с ботом
и четыре честных пункта. Инструкции по приложениям, ссылки на скачивание и
частые вопросы живут в боте (репозиторий `vpn/bot`, `northlink/spravka.py`)
и приходят в чат в момент, когда нужны: выбрал приложение — получил ссылку,
«Скачать» и шаги; кнопка «Вопросы» — ответы. На странице их больше нет.

- **Чат с ботом** — секция `#get`: кнопка «Получить доступ» шлёт `{}` на
  `https://cdn.adminwg.dad/api/chat/start` (бот northlink; код от `/invite`
  туда же полем `code`), в ответ приходят ссылка и сессия Matrix
  (`matrix.adminwg.dad`); ключ пробный на 7 дней, годовым его делает
  подписка на канал — кнопка в чате; дальше страница говорит с сервером
  сама — `/sync` длинным опросом, `PUT …/send`, картинки с жетоном.
  Библиотек нет, API клиента Matrix вызывается голым `fetch`. Кнопки — как
  в Telegram: inline-клавиатура под сообщением бота (поле
  `dad.adminwg.northlink.choices`: ряды кнопок, стили primary/success/danger,
  url со стрелкой; после нажатия — спиннер, бот правит сообщение через
  `m.replace`) и постоянная над полем ввода (событие состояния комнаты
  `dad.adminwg.northlink.keyboard`, сворачивается значком). Нажатие уходит
  как `body`=подпись и поле `dad.adminwg.northlink.press`. Сессия и ссылка
  лежат в `localStorage` (`northlink.matrix`, `northlink.issued`) — только
  в этом браузере. Два адреса, куда страница ходит после действия
  человека, — единственные внешние запросы; при загрузке их ноль.
- **Честно** — секция `#trust`, четыре пункта; тексты дублируются в боте
  («Вопросы» → «Что важно знать заранее»).
- **Бот** — ссылки `t.me/northlink_bot` в шапке и в чате.
- **Города** — строка над заголовком и в подвале.
- **Индексация** — `<meta name="robots" content="noindex, nofollow">` в `<head>`.
  Строка стоит намеренно: прямая ссылка работает, поисковики и сканеры
  блок-листов страницу не находят. Убирается одной правкой.

## Чего здесь нет

Адресов узлов, домена панели, ключей и любых других данных контура.
Инфраструктура живёт в отдельном закрытом репозитории; сюда попадает только
то, что и так видит любой человек с подпиской.
