# Northlink — лендинг

Одностраничный сайт личного VPN-контура: что это, где входные узлы и как
подключиться на iOS, Android, Windows, macOS и телевизоре.

Страница статическая и без единого стороннего запроса — ни аналитики, ни
библиотек, ни шрифтов с чужих серверов. Шрифты лежат рядом (`fonts/`, тот
же адрес), грузятся с `font-display: swap` и подогнанными запасными: текст
виден сразу, макет не прыгает. В сеть к боту страница выходит только по
действию человека.

## Дизайн: по правилам okno «Дизайн 2026» и «Фронт 2026»

С 13.09.2026 страница свёрстана по ранбукам проекта okno
(`~/Documents/okno/runbooks/дизайн-2026.md`, `фронт-2026.md`): одна
колонка шириной телефона (600 px) на любом экране — один макет вместо
двух; тёплые нейтральные без чистого белого и чёрного, один акцент
`#1F5A7A`, тема одна (тёмной нет — одна проверка контраста); Lora в
заголовках, Golos Text в тексте; контраст текста от 4,5:1 по токенам из
ранбука; цели нажатия от 44 px; поля ввода 16 px (Safari на iPhone иначе
приближает); без анимаций по прокрутке, сияний и градиентов; липкая кнопка
«Получить доступ», когда первый экран ушёл, — прячется, пока на экране блок
«Доступ» или чат. Токены — в `:root` в начале `<style>`.

Что из ранбука не взято и почему: чат на странице оставлен — он для тех,
у кого нет телеграма (в okno чат = Telegram); фото и цена — не про этот
сайт. Длина текста — 2 000 слов при норме ранбука до 1 020: сокращение
текста — отдельное решение владельца. Это не аскетизм: конфиг нужен ровно тогда, когда
туннель уже не работает, и страница обязана открыться на умирающем канале.

## Правки

Меняется один файл, публикуется коммитом в `main` — Pages пересобирает сам.

- **Адрес подписки** — блок «Ваша ссылка выглядит так» и `data-copy` у кнопки.
- **Бот** — секция `#access` и ссылки `t.me/...`; имя бота встречается в
  нескольких местах, менять все.
- **Города** — секция `#nodes`, по карточке на узел.
- **Приложения** — секция `#connect`, по вкладке на платформу.
- **Чат с ботом** — секция `#get`: кнопка «Получить доступ» шлёт `{}` на
  `https://cdn.adminwg.dad/api/chat/start` (бот northlink; код от `/invite`
  туда же полем `code`), в ответ приходят ссылка и сессия Matrix
  (`matrix.adminwg.dad`); ключ пробный на 7 дней, годовым его делает
  подписка на канал — кнопка в чате; дальше страница говорит с
  сервером сама — `/sync` длинным опросом, `PUT …/send`, картинки с жетоном.
  Библиотек нет, API клиента Matrix вызывается голым `fetch`. Кнопки — как
  в Telegram: inline-клавиатура под сообщением бота (поле
  `dad.adminwg.northlink.choices`: ряды кнопок, стили primary/success/danger,
  url со стрелкой; после нажатия — спиннер, бот правит сообщение через
  `m.replace`) и постоянная 2×2 над полем ввода (событие состояния комнаты
  `dad.adminwg.northlink.keyboard`, сворачивается значком). Нажатие уходит
  как `body`=подпись и поле `dad.adminwg.northlink.press`. Сессия и ссылка лежат в `localStorage`
  (`northlink.matrix`, `northlink.issued`) — только в этом браузере.
  Два адреса, куда страница ходит после действия человека, — единственные
  внешние запросы; при загрузке их по-прежнему ноль.
- **Цвета и шрифты** — токены `:root` и `@font-face` в начале `<style>`;
  менять по таблице контраста из ранбука okno, не на глаз.
- **Индексация** — `<meta name="robots" content="noindex, nofollow">` в `<head>`.
  Строка стоит намеренно: прямая ссылка работает, поисковики и сканеры
  блок-листов страницу не находят. Убирается одной правкой.

## Чего здесь нет

Адресов узлов, домена панели, ключей и любых других данных контура.
Инфраструктура живёт в отдельном закрытом репозитории; сюда попадает только
то, что и так видит любой человек с подпиской.
